# Legacy

Superseded protocols and working notes, kept for history. Nothing here is
installed: `bun scripts/install.ts` copies `skills/` only, so no agent reads
these files while it works.

- `protocols/`: earlier versions of the Squad, Business and Harness protocols.
  The current ones live in the skills (`skills/squads/SQUAD_PROTOCOL_V6.md`,
  `skills/businesses/BUSINESS_PROTOCOL_V2.md`, `skills/harness/SKILL.md`).
- `notes/`: build notes, proposals and a configuration reference that no
  longer matches the code. The settings are documented by `nrv config explain`.
